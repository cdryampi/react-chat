## Sobre el rework

La nueva versión, **SmartIoT Chat**, reconstruye la idea original del chat realtime con un stack moderno:

- Vite
- React
- TypeScript
- Tailwind CSS
- Firebase Auth
- Firebase Realtime Database
- GitHub Actions
- GitHub Pages

También incluye modo demo sin configurar Firebase, salas por defecto, presencia básica, adjuntos locales con IndexedDB y flujo de despliegue en GitHub Pages.
